# MyHousehold_System_Design

My Household Budgeting and Task Management System
This document includes all of the design information regarding a household budgeting and task management system.

Project Overview
A multi-member household will be able to use this proposed system to create, update and share budgets, transactions, and tasks using an MVC client server based on PostgreSQL.

Design Focus
•	MVC Client Server 
•	PostgreSQL Data Storage 
•	Multiple User Authentication 
•	Budget/Transaction Workflows 
•	Task Management Workflows 
•	Validation of Inputs/User Isolation from Data.

Documentation
All of the design for the entire system can be found in a PDF that is located in this repository.

Project Status
This is a design document for a system. The document details how the proposed system should operate; it does NOT detail how the system would be converted into a product application.
